The pattern under all seven

dlac's leaves are deep and well tested — arbResolve, resolveAmmoPlan, restockwatch.plan, digrank, fishcalc, equipcore.planSet, safewrite, idleexcl. The compositions that call them are shallow, hand-rolled, repetitive, and untested.

The project has felt this and responded by widening interfaces instead of deepening modules: 105 M._ exports across 23 files, 67 source comments that literally say "test seam", and 69 of dispatch.lua's 111 exports that exist only so tests can reach underneath the composition. M.dispatch — the function every trigger flows through — is called zero times by either test file.

The counter-example is already in the repo. equipcore.planSet(set, snapshot) takes a plain-table world and returns a plan; it needs no seams, and its tests are the least-stubbed in the suite. Each candidate below moves one composition toward that shape.

2 · Give the Statefile seam its write half

lib/statefile.lua (44 lines) · lib/safewrite.lua · craftwatch · helmwatch · fishwatch · chocowatch · ammowatch · pinwatch · arbwatch · restockwatch

Before

The module named after the seam owns only the string concatenation nobody argued about.

After

The same collapse ensureStateFile already performed on the read side — its own docstring records that it replaced six drifted clones.

Problem
The engine defends against torn writes with a drop-on-corrupt policy; nothing defends against producing them — 13 writers open the live file directly, and not one has a test.
Solution
statefile.open(name) returns a handle owning the path, the serializer and the safewrite ladder. Watchers stop knowing what a file is.
Wins
  • 13 writers → 1 implementation
  • 13 path composers deleted
  • Torn-write hazard closed
  • Write paths testable for the first time
  • locality: one durability guarantee
  • 8 guarded-require preambles deleted
Deletion test
Delete lib/statefile.lua today and 30 lines merely move back to 8 callers — three modules (gearui, lockstyle, macrobook) already bypass it and hand-roll the same answer. Delete the deepened one and 13 writers scatter again. That flip is the whole case.

Problem
Eight floating windows are wired by hand in an Ashita hook because the existing window registry sits behind the main box's early-return.
Solution

6 · Split the shared ui table — two tables fused into one

ui/gearui.lua:107-134 (21 declared) · 94 keys in use · 10 writing modules · gear/syncflags.lua:73-153

Before — one table, ten writers

_flagsDirty alone has 11 write sites across 7 modules, and 1 reader — any module can trigger a uiflags.lua disk write by setting a boolean. There is no markDirty().

After — the split is already enumerated
settings — ~15 persisted keys
get(k) · set(k, v)
owns the dirty flag and the write. The exact set is already listed at syncflags.lua:73-153.
per-frame scratch — ~79 keys
popup-open flags, edit buffers, hover caches — these move into the module that draws the widget. Not shared at all.

Mostly mechanical: the persisted half is already a written-down list, and the scratch half has exactly one legitimate owner each.

Problem
One table fuses a persisted preference set with a per-frame scratchpad, so ten modules mutate each other's state and render is not idempotent (hobbybar.lua:135 writes the selection from inside the draw call).
Wins
  • locality: widget state lives with its widget
  • Disk writes get one door
  • Tests stop poking a global to reach a clamp
  • Ownerless keys get owners
Related budget: the 200-local cap is the strongest force in this layer and it works — but it governs where code lives, not what depends on what. Every extraction relieved the local count while widening the bundle: deps is now 20 keys (no consumer uses more than 60%), host.services 38 (one dead, three unpinned). A companion budget on key count would stop the next extraction widening them again.

2 · Give the Statefile seam its write half

Because the project has already proved this exact collapse works, on the other side of the same seam. dispatch._ensureStateFile is 17 lines that absorbed six drifted readers behind (cache, filename) and carries ten tests; its docstring records the field lesson. The write half never got the same treatment, so 13 hand-rolled io.open calls produce the very torn files the reader was hardened to survive — and none of them can be tested, because there is no filesystem to fake.

It is also the smallest blast radius of the seven: addon-state only, no engine VERSION bump, no ADR touched, and the deletion test flips cleanly — deleting lib/statefile.lua today just moves 30 lines, deleting the deepened one scatters 13 writers.

The bigger prize is candidate 1. Its payoff recurs on every feature you ship, and the proof it works sits in the same file — but it touches M.dispatch, needs a version bump and a field round, so it wants a clear run rather than a first step.
