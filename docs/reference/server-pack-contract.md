# The server-pack contract (ADR 0035)

What a `servers/<id>/` pack must ship for dlac to mount it, and the shapes its
files must satisfy. The reference implementations: `servers/cexi/` (generated
by the maintainer's local CEXI pipeline) and `servers/vanaheim/` (generated by
the vanaheim repo's `tools/dlac-pack/gen_pack.py`). The per-pack gate is
`lua tests/pack_lint.lua <id>` — a pack that passes loads.

## Layout

```
servers/
  index.lua                  -- return { '<id>', ... }  (tracked; adding a pack is a commit)
  <id>/
    manifest.lua             -- the pack's declaration (below)
    data/<file>.lua          -- one Lua table per file, mounted as dlac\data\<file>
    modules/<name>/init.lua  -- optional pack modules (jobhelpers containment rules)
```

Selection: one pack installed → active. Several → `config\addons\dlac\server.lua`
(`return { server = '<id>' }`) chooses; without it the index's first pack wins
loudly. `serverpack.init()` mounts one `package.preload` entry per `files`
member; a file the manifest does not list does not resolve.

## manifest.lua

```lua
return {
    fmt  = 1,
    id   = '<id>',            -- MUST equal the folder name
    name = 'Display Name',
    maxLevel = 75,            -- serverpack.maxLevel(); every historical 75 reads this
    caps  = { ... },          -- capability flags; ABSENT = the feature does not exist
    const = { ... },          -- tuning constants; converted sites keep their historical fallback
    modules = { ... },        -- mount list AND order (tray/helper registration order)
    files   = { ... },        -- data mount list
    counts  = { <file> = n }, -- optional; pack_lint validates when present
}
```

Known caps: `ebox`, `prestige`, `ventures`, `gamemodes`, `giftbox`,
`disfavour`, `wearMainJobOnly`, `apostropheBridge`.
Known consts: `augFormat` ('cexi' | 'lsb'), `catalogMin`, `oneirosMpPct`,
`meritMaxMpCap`, `mpPlayerMultiplier`, `mpSjDivisor`, `moonOffset`, `teleWait`.
Unknown keys are ignored — an older dlac never breaks on a newer pack.

## catalog.lua — the contract that matters most

One nested table, walked ONLY by `gear/catalogindex.lua`:

- Top level: Slot buckets in any subset of
  `Main Sub Range Ammo Head Neck Ear Body Hands Ring Back Waist Legs Feet`.
- `Main`/`Range` nest one Category level (`Sword`, `Staff`, `Archery`, ...);
  records with no weapon category (skill-0 animators) sit FLAT at the slot
  level — the walker accepts a named record at either depth.
- A record is any table with `.Id` and `.Name`. The walker's two laws:
  rawIndex treats "has Id+Name" as an item and recurses everything else
  (skipping the key `NameToObject`); flatten treats "has Name" as an entry.

Fields the flattener promotes (a field missing here is silently absent
everywhere downstream): `Name` (the CLIENT's display spelling — dlac matches
live Ashita resource names at bag scan), `Level` (default 0), `Id`, `Jobs`
(`{"All"}` or `{"WAR", ...}` — an empty jobs mask is NOT "All": skip the row),
`Type`, `Stats` (keys = the statdefs vocabulary; unknown keys degrade to the
Misc section), and where applicable `OneHanded` (Main only), `AmmoType`,
`Pair` (`"<skill>:<subskill>"`, the Range/Ammo pairing law), `RSlot` (slots
the item reserves while worn, own bit masked out), `Model`, `Count`,
`AugKey`/`AugText` (augment-split records; the unpinned record keeps the
byId seat).

Table keys are PascalCase names with `+N` → `_N` (`makeKey`), unique per
slot/category bucket (`_2`, `_3` suffixes on collisions).

Stat scale conventions (the mod bridge owns them): `Haste` in percent,
DT-family (`DT/PDT/MDT/RDT/BDT`) in percent with sign, `SkillchainDamage` in
percent. `HELM = 1` is a flag, not a value.

## The other data files

- `spells.lua` / `abilities.lua`: arrays of
  `{ Name, Jobs = { WHM = 1, ... }, Skill?, MagicType?, Element? }` /
  `{ Name, Jobs, MainOnly?, SP? }` — vocabulary = LuaAshitacast strings.
- `zones.lua`: `[zoneid] = { n, t (ZONE_TYPE mask), m (ZONEMISC mask), town? }`.
- `gearsets.lua`: `[setId] = { pieces={ids}, min, max, tiers={[count]={Stat=val}} }`
  — tiers are value-at-count REPLACEMENT, contiguous `[min..max]`.
- `latentstats.lua`: `[itemId] = { { stat, add, cond = '<LATENT_NAME>', param }, ... }`.
- `levelscaling.lua`: `[itemId] = { { stat, add, from|below = <level> }, ... }`
  (latent 51 → `from`, latent 50 → `below`).
- CEXI additionally ships `crafts/nmdata/nmdrops/fooddb/fishdb/digdata/
  petmods/itembundles` — all optional; a feature whose file is absent
  degrades soft, which is the addon's standing failure mode.

## Pack modules

`servers/<id>/modules/<name>/init.lua` returns a table; optional `init(deps)`
and `pump()`. Everything else the module does itself at load: register
commands and packet handlers, `serverpack.provide('<service>', impl)` for the
questions core asks (`gamemode`, `prestige`, `eboxtrace`), and the UI
registrations (`tray.register`, `automationsui.registerHelper`). Core never
requires a `servers\` path — it asks `serverpack.service()` or lives without.
